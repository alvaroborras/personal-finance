# Personal Finance legal pages

Before publishing, replace every `REPLACE_WITH_YOUR_EMAIL` in `privacy.html` and `terms.html` with the data-protection contact email you will enter in Enable Banking.

Create a public GitHub repository containing these files, then enable **Settings → Pages → Deploy from a branch → main / root**. The URLs to enter in Enable Banking will be:

- `https://<github-user>.github.io/<repository>/privacy.html`
- `https://<github-user>.github.io/<repository>/terms.html`
