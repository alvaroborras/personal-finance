# Personal Finance legal pages

This public repository contains only the privacy notice and terms required for the Enable Banking consent flow. Never add credentials, private keys, account data, transaction data, or application source code here.

Enable **Settings → Pages → Deploy from a branch → main / root** for this repository. The published policy pages must be publicly reachable, but they contain no financial data or credentials. The URLs to enter in Enable Banking will be:

- `https://<github-user>.github.io/<repository>/privacy.html`
- `https://<github-user>.github.io/<repository>/terms.html`
